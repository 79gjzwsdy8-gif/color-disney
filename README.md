# Color Disney — pierwsza wersja

Aplikacja webowa w jednym pliku `index.html`, zaprojektowana pod iPhone'a.

## Funkcje
- biblioteka własnych stron ze zdjęciami
- 144 pozycje palety markerów, możliwość edycji numeru i próbki HEX
- stoper kolorowania
- galeria prac z datą i czasem sesji
- zapis danych w pamięci lokalnej przeglądarki

## Uruchomienie
Otwórz `index.html` w przeglądarce albo opublikuj pliki przez GitHub Pages.

## Ważne ograniczenia pierwszej wersji
- To nie jest jeszcze aplikacja natywna z App Store.
- Kolory palety są tymczasowymi podglądami, nie zweryfikowanym wzornikiem Languo.
- Nie ma wbudowanej kompletnej biblioteki Disney. Dodawaj strony ze swoich książek; nie kopiuj ani nie udostępniaj materiałów bez praw.
- Automatyczne rozpoznawanie kodów z kolorowanki i dobór najlepszego markera wymagają kolejnego modułu oraz wzorcowych danych kolorów.
- Dane zapisują się lokalnie na urządzeniu/przeglądarce; wyczyszczenie danych przeglądarki może je usunąć.
