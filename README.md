# Color Disney — wersja 2

Różowa aplikacja webowa do lokalnego katalogowania własnych książek i stron, stopera, sesji i galerii.

## Uruchomienie
Otwórz `index.html` w przeglądarce albo opublikuj pliki przez GitHub Pages.

## Ważne ograniczenia
- Katalog nie zawiera automatycznie wszystkich książek Disneya ani skanów. Dodaj własne egzemplarze i zdjęcia stron.
- Lista kodów Languo zawiera tylko kody zidentyfikowane z dostępnych wykazów. Nie wszystkie 144 odcienie zostały potwierdzone, a widoczne barwy są jedynie przybliżonym podglądem.
- Dane przechowywane są lokalnie w przeglądarce na tym urządzeniu. Przy dużej liczbie zdjęć pamięć może się zapełnić; użyj „Kopia danych” regularnie.
- Aplikacja jest podobna funkcjonalnie do aplikacji kolorowankowych, ale nie kopiuje ich zastrzeżonego kodu ani materiałów.
